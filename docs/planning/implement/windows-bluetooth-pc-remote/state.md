# Development status

- INC1 (Windows receiver and BLE GATT server) and INC2 (iPhone connects to the Windows GATT server) have source implementations.
- The Windows x64 source was cross-published from macOS, but the executable has not been tested on Windows and is not included in this repository.
- A Windows MSIX package and Windows/iPhone Bluetooth device verification are still needed.
- INC3 (iPhone advertises while Windows acts as GATT client) remains planned for broader adapter compatibility.
- INC4 covers integrated UI, setup guidance, and closeout after both BLE role directions are available.
